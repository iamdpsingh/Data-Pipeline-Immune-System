# ADR-010: Multi-Channel Free Mobile Operational Pulses
## Status: Accepted
## Context:
Paid telephony APIs (e.g. Twilio) add recurring cost for routine heartbeat status pulses.
## Decision:
Adopt official Meta WhatsApp Cloud API (1,000 free/mo), Telegram Bot API (100% free), and ntfy.sh.
## Consequences:
Guarantees zero-cost mobile alerting with instant push notifications.
